# Universal — News/Magazine Layout

Universal — адаптивная вёрстка новостного сайта в формате онлайн-журнала. Проект создан для портфолио и демонстрирует работу с компонентной HTML-структурой, SCSS-архитектурой по БЭМ, интерактивными элементами интерфейса и автоматизированной сборкой.

## О проекте

Макет представляет собой современную медиа-платформу с главным экраном, подборками новостей, рекламным баннером, статьями, блоком подписки и адаптивной навигацией. Основной фокус сделан на аккуратной pixel-perfect вёрстке, корректном отображении на разных разрешениях и поддерживаемой структуре кода.

## Стек

HTML · SCSS (БЭМ) · JavaScript · Gulp · Webpack · Swiper

## Что реализовано

- Адаптивная вёрстка по mobile-first подходу.
- Компонентная HTML-структура через `gulp-file-include`.
- Стилизация на SCSS с использованием БЭМ-методологии.
- Интерактивные элементы: табы, слайдер, мобильное меню и видео-модалка.
- SVG-спрайт для иконок.
- Оптимизация изображений: WebP и imagemin.
- Подключение favicon и web manifest.
- Production-сборка и автодеплой на GitHub Pages.

## Особенности

- Чистая файловая структура, удобная для масштабирования и поддержки.
- Разделение исходников и production-сборки.
- Автоматизация повторяющихся задач: сборка HTML, SCSS, JS, оптимизация ассетов и запуск dev-сервера.
- Подготовка проекта к публикации без ручной обработки файлов.

## Запуск локально

```bash
npm install
npm run dev    # dev-сервер с hot reload
npm run build  # production-сборка в папку app/
```

## Структура проекта

```
src/
├── partials/     # HTML-компоненты (gulp-file-include)
├── scss/         # Стили (BEM)
├── js/           # Скрипты
├── img/          # Изображения
└── resources/    # Шрифты, favicon, видео, данные
app/              # Сборка (не коммитится, генерируется при build)
```
